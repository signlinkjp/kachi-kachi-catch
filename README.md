# Kachi Kachi Catch（カチカチ キャッチ）

日本昔話「カチカチ山」をモチーフにした、**5×5 の詰みパズル**（年齢制限 4+）。
ウサギの **ウサギロー（Usagiro）** が十字に網を仕掛け、タヌキの **ポコ丸（Pokomaru）** の逃げ場をふさいで捕まえるゲームです。
Capacitor iOS アプリ（Bundle ID `jp.signlink.KachiCatch`）。現在は **Build 6**（ゲーム終了時に勝手にステージ選択へ飛ぶ不具合の修正・オープニングを全身キャラの走りに刷新）です。

---

## あそびかた

1. マスを1つタップすると、**そのマス＋上下左右の十字5マス**が反転（安全床 ↔ 罠床）。
2. 手を打つと、ポコ丸は **上下左右＋ななめの8方向** の安全床へ1歩逃げる（その場に留まることも）。
3. ポコ丸の逃げ場をすべて罠か岩でふさいだら **つかまえた！**
4. ステージごとに決められた手数（1手詰・3手詰・5手詰・7手詰）以内に捕まえればクリア。

### ルールの設計メモ（brief からの調整点）

brief のルールをそのまま実装すると、**「ポコ丸のいるマスをタップ＝十字5マスが罠＝1手で必ず詰み」** になり、
3手詰・5手詰・7手詰が原理的に成立しませんでした。そこで次の2点だけ調整しています（画面の「あそびかた」にも明記）。

| 調整 | 理由 |
| --- | --- |
| **ポコ丸のいるマスはタップできない**（素早いタヌキの真下には網を仕掛けられない） | 1手詰の自明な手をなくし、「隣のマスから十字で囲う」という本来のパズルにする |
| **逃げ道を8方向にした**（十字フリップは斜めを塗れない） | 1手詰〜7手詰の階段が自然に成立し、深い問題でも「どんな逃げ方をされても必ず詰む」ゲーム木が閉じる |

この2点により、全問が **AND/OR ゲーム木探索** で「プレイヤーが最善を尽くせば、ポコ丸がどの合法手を選んでも指定手数以内に100%詰む」と証明できます。

## Build 6 で直したこと・足したこと

### 1. 「ゲームが終わると勝手にステージ選択画面へ飛ぶ」不具合（実機報告）

ステージの最後の1手を打って失敗（`にげられた…`）した瞬間、結果カードが出るのとほぼ同時に
ステージ選択画面へ飛ばされていた。原因は **iOS のゴーストクリック**:

- 盤面のタップは `pointerdown` で即座に1手を確定し、失敗カードはその **240ms 後**（クリアは 620ms 後）に出す。
  カードは画面の中央に出るので、**盤面の下段のマスはちょうどカードの「ステージをえらぶ」ボタンの下**に重なる
  （393×852 でマス 20・21・22・24 が該当）。
- 指を離した瞬間の `click` は「そのとき指の下にある要素」へ飛ぶため、押しっぱなし（または素早い2回目のタップ）だと
  出たばかりの「ステージをえらぶ」に当たり、ゲーム終了と同時に画面が切り替わっていた。

対策（`src/main.js` / `styles.css`）:

- **結果カードを出した瞬間から 520ms は、カード内のボタンを受け付けない**
  （`.overlay.arming .card-actions { pointer-events: none; }` ＋ JS 側でも `preventDefault`）。
- **カードが出る前に始まったタップから出た `click` は、いつ届いても捨てる**
  （`pointerdown` の時刻とカードを出した時刻を比べる。次に新しいタップが始まるまで有効）。
- **カードが出たあとに始まった新しいタップなら、その場でガードを解く**
  （登場アニメの最中でも、本人が押しにいった操作は待たせない）。
- 指から出た `click`（`isTrusted`）だけを対象にし、スクリプト・支援技術の `click` は通す。
- クリア・失敗・タイムアタック結果の**3種類のカードすべて**に同じガードを張り、
  `tapCell` / `onCaught` / カード表示処理の中に `nav()` が無いこと（勝手な画面遷移が他に無いこと）もテストで固定。

E2E（`tools/e2e-build6.mjs`）では、**本物の触タップ**で
「下段のマスを押しっぱなし → カードが出る → 指を離す」を再現し、
ステージ選択へ飛ばずカードのままであること、
2回続けて叩いても飛ばないこと、ガードが明けたあとは普通に押せることを確認している
（修正前はこの手順で `screen: "select"` になっていた）。

### 2. オープニングを「丸枠なしの全身キャラ」に刷新

丸アイコン（`rabbit_token.png` / `tanuki_token.png`）が横切る形をやめ、
**臼の杵を持ったウサギローと逃げるポコ丸の全身**が、足を動かして右から左へ走り抜ける。

- 素材は **4コマの走りスプライト**（`assets/rabbit_run.png` / `assets/tanuki_run.png`）。
  背景はマゼンタで生成 → 色距離で透過＋アンミックス（`tools/extract_runsprites.py`）して
  **枠も四角い下地もない透過 PNG** にした。
- コマ送りは `steps(1, end)` の `background-position`（1コマ分の幅は `calc(var(--fw) * 4)` で決め打ち）、
  移動と弾みは `transform` / `opacity` だけ。`will-change` で合成レイヤーに載せ、iOS の WKWebView でも軽い。
- 走り去ったあとにタイトルがポンと出る（走り 1.5 秒・全体 2.1 秒・タップで即スキップ）。
- 走りスプライトは `<link rel="preload">` で先に読み込む。

## Build 5 で足したこと

### 1. オープニングの「追いかけ」アニメ（Build 6 で全身キャラ版に刷新）

アプリ起動時（1.6秒・タップで即スキップ・全体は1.75秒でホームへ）、
ポコ丸が慌てて右から左へ逃げ、**臼の杵を持ったウサギロー**がトテトテ追いかけて横切り、
最後はホーム画面と同じ2人の位置へ着地する。

- 動かすのは **`transform` と `opacity` だけ**（`will-change: transform, opacity`）。`left` / `width` / `filter` は動かさない。
- 追いかけの層は `pointer-events: none`。`#screen-opening.playing` のときだけ動き、
  画面を離れると `playing` が外れて **opacity 0・アニメ停止**（透明な幕も残らない）。
- 走る速さは横のスピード線・砂煙・汗で表現（これも transform / opacity のみ）。

### 2. クリア・結果カードの「📤 シェアする」

- **Web Share API（`navigator.share`）優先** — iOS の WKWebView では標準の共有シートが開く。
- 非対応環境（PC ブラウザ等）は **クリップボードにコピー＋「結果をコピーしました」トースト**。
  シートを閉じただけ（`AbortError`）のときは勝手にコピーしない。
- 文言は12言語（`src/share.js` ＋ `i18n.js` の `share.*`）。日本語の例:
  `「カチカチ キャッチ」STAGE 49 をクリア！🐇🪵🦝` / `ウサギローとポコ丸の5×5詰みパズル` / `#カチカチキャッチ #KachiKachiCatch`

## Build 4 で直したこと（実機フィードバック4点＋ステージ選択画面のフリーズ）


### 0. 「ステージ選択画面で何も押せない・スクロールできない・←が効かない」（実機フリーズの真因）

クリアカードの「ステージをえらぶ」で `nav("select")` したとき、`#overlay.show`（透明になった全画面の受け皿）が残っていた。
`.screen` は `pointer-events: none` でも、子の `.overlay.show` が `auto` のままだと透明でもヒットテストに引っかかり、
次の画面のタップもスクロールも全部食べる（＝盤面もカードも押せない「フリーズ」に見える）。

- `nav()` で必ず `closeOverlays()`（クリア/失敗カード・シート・トースト）を閉じる。`resetInteraction()` でもカードを畳む。
- CSS で `.screen:not(.active), .screen:not(.active) * { pointer-events: none !important; }`（非表示の画面は中身ごと触れない）。
- スクロール領域に `min-height: 0` / `touch-action: pan-y` / `overscroll-behavior: contain` を明示。
- 見張り番（1.2秒）が「透明なオーバーレイ」「決着したのにカードが出ない」を自己修復する。
- E2E に「クリア→ステージをえらぶ→下までスクロール→激ムズをタップ→←でホーム」を追加（`tools/e2e-build4.mjs`）。

### 1. ウサギローとポコ丸が同時に喋る

声は **必ず1本ずつ**（`src/audio.js` の掛け合いキュー）。前の声が終わって 0.15 秒あけてから次を鳴らす。
連打時は待機中の古い声を捨てて最新の1本だけ待つので、声が溜まらない。
ネイティブ（`AppDelegate.swift`）側も、鳴らす前に鳴っている声を全部止める。
また `AVAudioPlayer(contentsOf:)` の読み込みはバックグラウンドキューへ移し、`AVAudioSession` の起こし直しは2秒に1回までにした（タップのたびにメインスレッドで setActive しない）。

### 2. 声質の交換

| キャラ | 日本語 | 英語 | トーン |
| --- | --- | --- | --- |
| ウサギロー | `ja-JP-NanamiNeural` | `en-US-AnaNeural` | pitch `+30Hz` / rate `+12%`（明るく元気） |
| ポコ丸 | `ja-JP-KeitaNeural` | `en-US-BrianNeural` | pitch `+8Hz` / rate `+8%`（丸み・お調子者） |

`tools/voices.json` を更新し、`tools/gen_voices.py` で ja/en 計38本を再生成（`assets/voices/` → `www/`）。

### 3. ホームの「🌐 日本語」削除と「⚙ 設定」の視認性

- 言語切替は「設定 > 言語」に一本化（ホームの言語チップを削除）。
- 設定ボタンは ステージ／あそびかた と同じ `menu-btn` の見た目（濃い文字色 `--verm-dark`・はっきりした枠線・同じ文字サイズ）で中央配置。

### 4. 叩く/逃げるアニメーション

- ウサギロー: 約0.52秒（Build 3 は0.3秒）。ポンと出る → 木槌を振り上げ → **ドン！**（290ms に効果音・バイブ・衝撃波リング）。
- ポコ丸: 約0.42秒（Build 3 は0.3秒）。**ビクッ**（scale .9/1.14）→ 放物線でぴょーん（回転つき）→ 着地でつぶれる。足元に砂煙。
- どちらも `transform` と `opacity` だけの GPU 合成で、`await` しない（連打しても次の手は即通る）。

### Build 3 で直したこと

### 1. 「2ステージやったら固まる」「操作がもたつく」

- **タップの待ち行列（`app.busy`）を廃止**しました。Build 2 は `await`（反転アニメ → 170ms 待ち → ポコ丸の跳ね → `Element.animate().finished`）で
  1手ずつロックしていたため、iOS で promise が返らない場面（裏に回る・アニメが中断される等）で盤面が押せないまま残り得ました。
  いまは **タップした瞬間に同期で局面が確定**し、演出は投げっぱなし（`onfinish` のみ）です。ロックが残る経路がありません。
- **押した瞬間に反応**：`pointerdown` で1手を確定し、`pointerup` → `click` は同じ指の二度打ちをはじくだけ。
  `pointercancel`（iOS の指の微動）でも手は失われません。同じマスの 180ms 以内の連打だけ1回に丸めます。
- **1手あたりの計算を軽くした**：`Game.play()` から「まだ詰むか」の再探索（深い面で実測 268ms）を削除し、
  ポコ丸の応手は9方向の候補を1つの memo で共有。上級7手詰でも **1手 40ms 未満**（実測）になりました。
- **レイアウトの測り直しをキャッシュ**：25マス×毎タップの `getBoundingClientRect` をやめ、ステージ開始・回転・文字サイズ変更のときだけ測定。
- **重い描画を削除**：動くコマの `filter: drop-shadow`、全画面の `mix-blend-mode`、オーバーレイの `backdrop-filter` を撤去（iOS の再描画ストーム対策）。
- **見張り番**：1.2秒ごとに「アニメが止まっていないか」を見て、止まっていたら位置を合わせ直します。復帰（visibilitychange）でも盤面を描き直します。

### 2. ウサギロー・ポコ丸の声が聴こえない

- 声は **ネイティブの `AVAudioPlayer`（`KachiAudioPlugin.playVoice`）** で鳴らします。
  Web Audio は「タップと同じ瞬間」でないと AudioContext が起きず、`fetch` → `decodeAudioData` をはさむと実機で無音になり得たためです。
  ブラウザ（開発・E2E）では従来どおり Web Audio → `HTMLAudioElement` にフォールバックします。
- **話者ごとに別チャンネル**：Build 2 は声を鳴らすたびに前の声を止めていたため、「ウサギローのひと声 → ポコ丸のセリフ」が続く場面で
  後から来た声に食われてほぼ無音でした。いまはウサギローとポコ丸は重なり、同じ話者だけ差し替えます。
- **BGM ダッキング**：声が鳴っている間だけ BGM を 0.3 → 0.084 に下げ、終わったら戻します（声は 1.0）。
- **先読み**：起動時・言語変更時にその言語の声19本を読み込みます（`preloadVoices`）。
- **語尾を切らない**：タップの「ウサギローの声」は 1.7 秒に1回まで、開始の声は 1.05 秒遅らせてポコ丸とぶつけません。
- `WKWebView.configuration.mediaTypesRequiringUserActionForPlayback = []` も設定（保険）。

### 3. ホームの見た目

- キャラ絵は**木槌の先端からポコ丸のしっぽまで全体**が入る大きさに（幅と高さの両方を見て `layoutHero()` が決定）。148% 拡大とマスクによる見切れを廃止。
- 名前ラベルは**白い太縁のポップ文字＋左右に3本の飾り線**（ウサギロー=青／黄、ポコ丸=緑／黄緑）。12言語で見切れないようフォントを自動調整。
- 「5×5 詰みパズル」は**白地＋太いオレンジ赤枠＋左右に黄色の3本線**。
- キャラ絵の地色とページ背景の境目を消すぼかしを追加。

## ソルバー（`src/solver.js`）

- 状態＝罠ビットマスク（25bit）＋ポコ丸の位置。AND/OR 探索（反復深化・メモ化）で
  **最短手数** と **全応手に対する詰み** を同時に証明します。
- `solveState(state, geom, {limit})` → `{distance, moves[]}`（`limit` 手以内に必ず詰むか）
- `exactDistance()` → 最短手数ちょうど
- `tanukiReply()` → ポコ丸AI（最も長く生き残る手を選ぶ）
- `principalLine()` / `src/solutions.js` → 全170問の最善手順を事前計算（起動時の計算ゼロ）

### 検証（`npm test`・344テスト）

- ルール（十字5マス・8方向の逃げ道・タップ不可マス）の単体テスト
- ソルバーと**素朴実装（メモ化なしの配列版）**の総当たり照合
- **通常50問**: 最短手数＝par（par−1では詰まない）／初手のあと**ポコ丸の全合法手**が par−1 手以内に詰む
- **デイリー120問**: 全問で最短手数＝par、盤面の使い回しなし、日付→問題の決定性と120日周期
- ゲーム進行（ヒントに従うとちょうど par 手でクリア／外すと失敗／やりなおし）
- 12言語のキー完全一致・キャラ名・言語フォールバック
- 無料/PRO の線引き（25問・タイムアタック・過去デイリー・ヒント回数）
- ボイス（日英の mp3 が全セリフそろう・容量・場面ごとのバリエーション）
- タイムアタックのベストが60/120/180秒で別・古い保存の引き継ぎ・文字サイズの丸め

- **ウサギローの網**: タップしたマスに0.3秒だけ登場して木槌を「ポンッ」、十字に網が広がる（`usagiroSwing()`）。連打を止めないテンポ
- **捕獲**: ネットが落ちて火花・紙吹雪、クリアカード
- **音**: WebAudio で効果音とループBGMを合成。設定で BGM／効果音／ボイス ON-OFF。**ホーム画面から戻ると必ず鳴る**（suspended→resume、戻らなければ AudioContext を作り直す）
- **ボイス**: ウサギローとポコ丸が場面ごとに声で喋る（日本語・英語の mp3 を `assets/voices/` に同梱、計約170KB）。場面ごとに2〜4パターンをローテーション、連打時は前の声を止める
- **バイブ**: iOS ネイティブ `KachiHapticsPlugin`（UIImpactFeedbackGenerator）。設定で ON-OFF
- **12言語**: 日本語 / English / 简体中文 / 繁體中文 / 한국어 / Español / Français / Deutsch / Português / Italiano / हिन्दी / Bahasa Indonesia（未対応端末は英語）。タイトルと設定の 🌐 から切替。ラベル・あそびかた・PRO案内も12言語
- **文字サイズ**: 設定で 標準 / 大 / 特大（12言語・即時反映・保存）
- **レイアウト**: iPhone 375/393/430・特大文字・iPad（`TARGETED_DEVICE_FAMILY = "1,2"`）で検証済み。ホームはキャラ・ロゴ・ボタンを一回り大きくし、キャラ名ラベル（ウサギロー／ポコ丸）を頭上に配置
